## 🚀 Getting Started

You don’t have to ever use `eject`. The curated feature set is suitable for small and middle deployments, and you shouldn’t feel obligated to use this feature. However we understand that this tool wouldn’t be useful if you couldn’t customize it when you are ready for it.

1. **Clone the repository**

   ```bash## Learn More

   git clone https://github.com/keerthana-ravi-thoddoon/portfolio-with-react.git

   cd portfolio-with-reactYou can learn more in the [Create React App documentation](https://facebook.github.io/create-react-app/docs/getting-started).

   ```

To learn React, check out the [React documentation](https://reactjs.org/).

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm start
   ```

4. **Open the browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 💅 Customization

### Colors
The color theme can be customized in `tailwind.config.js`:
```js
colors: {
  primary: '#1a1b26',
  secondary: '#bb86fc',
  textPrimary: '#e5e9f0',
  textSecondary: '#a9b1d6',
}
```

### Content
Update the content in respective section components under `src/sections/`
